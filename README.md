## 안녕하세요

에스라봉을 즐기면서 용병을 키우거나 스킬과 유물을 바꿀 때, 직접 확인하고 반복해야 하는 부분을 조금 편하게 만들고 싶어서 시작한 개인 프로젝트입니다.

처음에는 제가 쓰려고 필요한 기능을 하나씩 붙였는데, 다른 분들도 편하게 써 보실 수 있도록 **에슬라봇**이라는 이름으로 공유하게 됐습니다. 게임을 계속 즐기는 동안 필요한 부분을 조금씩 보완해 갈 생각입니다. 다만 개인 취미로 만드는 도구라 모든 패치에 바로 대응하거나 일정한 업데이트 주기를 약속하기는 어렵습니다.

육성 기준과 추천에는 커뮤니티 공략과 게임 내 정보를 참고했습니다. 제가 잘못 이해했거나 계산에 빠뜨린 부분이 있을 수 있으니 추천 결과는 참고용으로 봐 주세요. 잘못된 내용, 불편한 점, 있으면 좋을 기능 모두 편하게 의견 주시면 좋겠습니다.

## 어떤 방향으로 만들고 있나요?

**순정 게임의 기본 콘텐츠와 성장·추첨 규칙을 유지하면서, 원래 있는 기능을 더 편하게 사용하도록 돕는 것**이 목표입니다. 기존 성장·환생·스킬 교체·유물 재설정 기능을 활용하고, 그 위에 반복 작업 자동화와 결과 비교·정보 표시를 더하는 방향으로 개발하고 있습니다. 용병을 어떻게 키울지 비교하거나, 스킬·유물에서 원하는 결과를 찾거나, 전투 결과를 살펴보는 일을 조금 더 편하게 하려고 만들었습니다.

성장·환생·스킬·유물의 결과 탐색에는 게임에 구현된 결과 생성 기능을 활용합니다. 능력치의 한계나 추첨 테이블을 임의로 높이는 기능 대신, 기존 기능을 이용하는 반복 작업과 결과 확인을 보조하는 데 초점을 맞춥니다.

- **반복 작업 줄이기:** 성장·환생 결과 탐색, 스킬·유물 자동 리롤, 저장·불러오기
- **판단에 필요한 정보 모으기:** 육성·카드 추천, 능력치 비교, 딜·힐 미터기와 전투 분석
- **조작 편의 보완하기:** 유물 프리셋, 정렬·검색, 단축키와 추가 배속
- **원본 설치 보존하기:** Steam 게임 설치 폴더를 직접 덮어쓰지 않고, 별도 실행 환경과 저장본을 사용

분류상으로는 **편의성(Quality of Life, QoL) 모드**라고 설명하는 것이 가장 가깝습니다. 게임 안에 UI와 자동 탐색·저장·불러오기 기능을 추가하므로, 순정 게임과 모든 동작이 완전히 같다는 뜻은 아닙니다.

특히 자동 리롤은 여러 결과를 탐색해 조건에 맞는 결과를 선택하고 실패한 시도를 복구합니다. 따라서 실패한 시도의 비용을 모두 지불하는 일반 연속 플레이와는 진행 방식이 다릅니다. **원본 설치를 보존한다는 점과, 플레이 중 편의 기능이 추가된다는 점을 구분해서 봐 주세요.**

- **보유 용병 유물 가져오기:** 출전 선수 카드의 유물 버튼 → 주전·교체 용병 카드 선택 → 두 슬롯 일괄 장착
- **전투 분석 확장:** 다른 용병 A/B 비교, 식별된 유물·CC 기여, DPS/HPS 등 효율 지표
- **선수단 카드 등급:** 레벨 옆 체/공/방/속 등급과 1레벨·현재 기준 전환
- **마켓 미확인 필터:** 스크롤 표시·클릭·키보드 선택으로 확인 기록, SAAA 이상·샤이니·챔피언 유지

## 처음 사용하는 방법

사용 환경은 **Windows x64 + Steam에 설치된 에스라봉**입니다. 런처에 필요한 .NET이 포함되어 있어 Codex나 개발 도구를 따로 설치할 필요가 없습니다.

1. Steam에서 에스라봉을 설치하고 게임에서 캠페인을 한 번 저장합니다.
2. 게임을 저장하고 종료합니다.
3. **[EslabotLauncher-win-x64-1.0.24.zip 다운로드](https://github.com/Eslabot/eslabot/releases/download/v1.0.24/EslabotLauncher-win-x64-1.0.24.zip)**를 누릅니다. Releases 페이지에서 받는 경우 아래쪽 **Assets**를 펼쳐 같은 파일명을 선택합니다. 초록색 Code 버튼이나 Source code ZIP은 사용하지 않습니다.
4. 내려받은 ZIP을 우클릭해 **압축 풀기**를 선택하고 PC의 로컬 폴더에 전체 압축을 풉니다. 게임 설치 폴더에 덮어쓸 필요는 없습니다.
5. 압축을 푼 폴더 안의 **에슬라봇 런처.exe**를 실행합니다. 설치 마법사 없이 창이 열립니다.
6. 게임 설치 위치를 확인합니다. 자동으로 찾지 못하면 **게임 위치**에서 지정합니다.
7. **최신 버전 동기화**를 누릅니다.
8. **사용 가능**이 표시되면 **에슬라봇 실행**을 누릅니다.

최초 준비 때는 설치된 게임 데이터를 PC 안에서 약 2GB 복사·검증합니다. 게임 데이터가 변경된 새 빌드에서도 새 로컬 사본을 준비할 수 있습니다. 배포 파일에는 게임 원본이나 개인 세이브가 포함되어 있지 않습니다.

기존 개발용 모드를 사용했다면 **처음 동기화하기 전에 [기존 모드 가져오기]에서 기존 runtime 폴더를 선택**해 주세요. 이미 새 모드 저장본이 있으면 덮어쓰지 않도록 가져오기를 제한합니다.

## 게임이나 모드가 업데이트됐을 때

**게임 저장·종료 → Steam에서 게임 업데이트 완료 → 런처 실행 → 최신 버전 동기화 → 사용 가능 확인 → 에슬라봇 실행**

- 개발자가 검사·수정해서 공개한 호환 버전을 받아 적용합니다.
- 런처 업데이트가 포함되면 런처 자체를 갱신하고 다시 엽니다.
- 미검증 게임 빌드는 **에슬라봇 실행**에서 매번 경고를 확인하고 시도할 수 있습니다. 기능·저장 호환이 보장되지는 않으며, 알려진 문제 빌드는 실행할 수 없습니다.
- 게임 패치 분석과 수정본 공개는 개발자가 진행합니다. 사용자의 동기화 버튼은 공개된 검증본을 받는 기능입니다.
- 게임을 실행 중이라면 저장하고 종료한 뒤 동기화해 주세요.

## 세이브는 어떻게 관리하나요?

모드 저장본과 설정은 기본적으로 **`%LOCALAPPDATA%\Eslabot\data`**에 따로 보관합니다. 런처의 **저장 폴더** 버튼으로 열 수 있습니다.

- 처음에는 기존 게임 저장본을 복사해 별도 모드 환경을 준비합니다.
- **1.0.5부터 모드에서 저장한 캠페인 진행본을 공식 Steam 저장 폴더에도 자동 반영합니다.** 별도로 파일을 옮길 필요가 없습니다.
- 온라인 실행 전에 Steam의 기존 저장 상태를 확인하고, 게임 종료 후 Steam 클라이언트의 업로드 완료 응답과 파일 해시를 대조합니다. **런처에 ‘Steam Cloud 동기화 완료’가 표시될 때까지 기다려 주세요.**
- Steam 로그인과 게임의 Steam Cloud 사용 설정이 필요합니다. 저장 즉시 서버 업로드가 끝나는 방식은 아니며, 오프라인·연결 오류·용량 부족 시에는 로컬 저장본을 보존하고 동기화 대기로 표시합니다.
- Steam과 모드에서 각각 진행해 저장본이 달라졌다면 사용할 진행본을 직접 선택합니다. 기존 파일은 로컬에 백업하며 서로 다른 진행을 자동으로 합치지 않습니다.
- 모드 업데이트 시 프로그램 버전과 저장본을 분리해 유지합니다.

Steam Cloud 연동 대상은 게임의 캠페인 저장 파일입니다. 모드 전용 설정·분석 기록·배속 설정는 로컬 데이터 폴더에 보관하며, 배포 서버에는 개인 세이브를 전송하지 않습니다. **1.0.4 이하를 사용 중이라면 먼저 최신 버전 동기화로 런처를 갱신해 주세요.**

자세한 저장·불러오기 동작과 난수 옵션은 [상세 가이드](docs/USAGE.md#저장과-불러오기-f5f10)를 확인해 주세요.

## 피드백과 현재 검증 범위

기능 구현에 초점을 맞춘 개인 프로젝트라 성능 최적화를 충분히 고려하지는 못했습니다. PC 사양과 플레이 상황에 따라 렉이나 처리 속도 차이가 있을 수 있으니, **필요한 기능만 상황에 맞게 선택해서 사용해 주세요.** 미터기와 전투 기록 수집은 필요에 따라 켜고 끌 수 있습니다. 실행이 잘 안 되거나 특정 기능이 정상적으로 작동하지 않으면 편하게 문의해 주세요.

문제가 있다면 공유 글의 댓글 등 피드백을 남기는 곳에 **게임 버전, 모드 버전, 사용 기능, 재현 순서, 오류 문구**를 함께 적어 주세요. 아이디어와 수정 제안도 환영합니다. 화면이나 기록을 공유할 때 개인 정보가 포함되지 않았는지 확인해 주세요.

현재 배포 버전은 **에슬라봇 1.0.24**입니다. 기존 검증 게임 기준은 **0.84.2 / Steam 빌드 26136997**이며, 그 밖의 빌드 경고 실행은 호환성 승인을 뜻하지 않습니다. 이번 추가분은 가상 저장·런처 갱신·UI 검사로 확인했고 실제 게임 플레이 검사는 다시 진행하지 않았습니다. 정확한 패키지·서명·개인정보와 공개 다운로드는 별도로 확인합니다. 다른 실물 PC나 독립 Windows VM 검증은 아직 완료하지 않았습니다.

이 프로젝트는 게임 제작사와 별개인 개인 비공식 도구입니다. 추천은 모든 용병과 상황에 대한 절대적인 최적해가 아닙니다. 중요한 플레이 전에는 별도로 세이브를 백업해 주세요.

**기능별 사용 순서와 설명은 [상세 사용 가이드](docs/USAGE.md)에 정리했습니다.**



### 마켓 확인 기록과 표시 유지

목록창에 용병 행이 절반 이상 표시되면 확인한 용병으로 기록합니다. 처음 보이는 목록도 포함하며, 클릭·키보드 직접 선택도 확인 처리합니다. 현재 목록을 즉시 지우지 않고 다음 목록 갱신 때 숨깁니다.

확인했어도 최초 1레벨 체력·공격·방어·속도의 등급 점수 합계가 21점 이상(S=6, A=5, SAAA 이상)이거나 샤이니·챔피언인 용병은 계속 표시합니다. 판매 종료·구매 완료 등 게임 기본 제외 조건과 선택한 신규·스카우터 등의 필터는 그대로 적용합니다.


### 게임 업데이트 후 실행

게임 빌드가 검증 목록과 달라도 별도 확인창 없이 기존 실행 버튼으로 진행합니다. 이미 사용할 수 있는 모드가 있으면 버전 차이만으로 시작 시 동기화를 반복하지 않습니다. 모드 업데이트는 최신 버전 동기화 버튼을 사용하세요.

실행 전 온라인 차단 정보는 짧게 조회하며 연결 지연 시 최근 서명 정보와 알려진 차단 목록을 유지해 진행합니다. 실제 문제가 확인된 현재 게임 빌드, 모드 파일/서명 손상과 저장 충돌 처리는 유지합니다. 지원 목록 밖의 모든 게임 기능이 검증됐다는 의미는 아닙니다.

## 실행이 안 되거나 오류가 날 때

런처 아래의 큰 **「실행이 안 되나요? 여기 눌러 알려주세요」** 버튼을 눌러 주세요. 어떤 버튼을 눌렀고 어디에서 멈췄는지 적은 뒤, 자동 생성된 진단 내용을 확인하고 **진단과 설명 보내기**를 누르면 됩니다. 실제 접수가 완료되면 접수 번호가 표시됩니다. 전송 실패를 완료로 표시하지 않습니다.

- 설명과 진단은 공개 게시글이 아닌 **비공개 접수함**으로 전달됩니다. 답변받을 이메일·연락처는 선택 사항입니다.
- 버전·게임 빌드·실행 파일 존재 여부·최근 오류 일부만 수집하며, 세이브와 계정 정보·전체 플레이 기록은 자동 첨부하지 않습니다. 진단의 개인 경로·인증 정보는 전송 전에 가립니다. 설명에는 비밀번호나 인증 코드를 적지 마세요.
- 전송 전에 진단을 확인할 수 있으며 동의 없이 자동 전송하지 않습니다. 서버에는 암호화해 보관하고 접수함은 30일 기준으로 자동 정리합니다. 서비스 운영 백업에는 제공업체의 보존 정책이 적용됩니다.
- 런처의 메인 화면이 열리지 않으면 압축을 푼 폴더의 **실행 문제 문의.cmd**를 실행해 문의 창만 열 수 있습니다. EXE 자체가 열리지 않으면 **[웹 문의 페이지](https://eslabot-support.pages.dev/)**에서 증상을 적거나 저장한 진단 JSON을 첨부할 수 있습니다. 인터넷 접속이 안 되면 **진단 파일 저장**을 선택해 두었다가 다시 보내 주세요.
