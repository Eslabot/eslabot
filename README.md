## 안녕하세요

에스라봉을 즐기면서 용병을 키우거나 스킬과 유물을 바꿀 때, 직접 확인하고 반복해야 하는 부분을 조금 편하게 만들고 싶어서 시작한 개인 프로젝트입니다.

처음에는 제가 쓰려고 필요한 기능을 하나씩 붙였는데, 다른 분들도 편하게 써 보실 수 있도록 **에슬라봇**이라는 이름으로 공유하게 됐습니다. 게임을 계속 즐기는 동안 필요한 부분을 조금씩 보완해 갈 생각입니다. 다만 개인 취미로 만드는 도구라 모든 패치에 바로 대응하거나 일정한 업데이트 주기를 약속하기는 어렵습니다.

육성 기준과 추천에는 커뮤니티 공략과 게임 내 정보를 참고했습니다. 제가 잘못 이해했거나 계산에 빠뜨린 부분이 있을 수 있으니 추천 결과는 참고용으로 봐 주세요. 잘못된 내용, 불편한 점, 있으면 좋을 기능 모두 편하게 의견 주시면 좋겠습니다.

## 어떤 방향으로 만들고 있나요?

**순정 게임의 기본 콘텐츠와 성장·추첨 규칙을 유지하면서, 원래 있는 기능을 더 편하게 사용하도록 돕는 것**이 목표입니다. 기존 성장·환생·스킬 교체·유물 재설정 기능을 활용하고, 그 위에 반복 작업 자동화와 결과 비교·정보 표시를 더하는 방향으로 개발하고 있습니다. 용병을 어떻게 키울지 비교하거나, 스킬·유물에서 원하는 결과를 찾거나, 전투 결과를 살펴보는 일을 조금 더 편하게 하려고 만들었습니다.

성장·환생·스킬·유물의 결과 탐색에는 게임에 구현된 결과 생성 기능을 활용합니다. 능력치의 한계나 추첨 테이블을 임의로 높이는 기능 대신, 기존 기능을 이용하는 반복 작업과 결과 확인을 보조하는 데 초점을 맞춥니다.

- **반복 작업 줄이기:** 성장·환생 결과 탐색, 스킬·유물 자동 리롤, 저장·불러오기
- **판단에 필요한 정보 모으기:** 육성·카드 추천, 능력치 비교, 딜·힐 미터기와 전투 분석
- **조작 편의 보완하기:** 유물 프리셋, 정렬·검색, 단축키와 추가 배속
- **원본 설치 보존하기:** Steam 게임 설치 폴더를 직접 덮어쓰지 않고, 별도 실행 환경과 저장본을 사용

분류상으로는 **편의성(Quality of Life, QoL) 모드**라고 설명하는 것이 가장 가깝습니다. 게임 안에 UI와 자동 탐색·저장·불러오기 기능을 추가하므로, 순정 게임과 모든 동작이 완전히 같다는 뜻은 아닙니다.

특히 자동 리롤은 여러 결과를 탐색해 조건에 맞는 결과를 선택하고 실패한 시도를 복구합니다. 따라서 실패한 시도의 비용을 모두 지불하는 일반 연속 플레이와는 진행 방식이 다릅니다. **원본 설치를 보존한다는 점과, 플레이 중 편의 기능이 추가된다는 점을 구분해서 봐 주세요.**

| 육성·카드 추천 | 보유 용병별 육성 목표 관리, 능력치·스킬·특화·마스터리 선택 비교, 카드 선택창 옆 추천 |
| 환생 훌훌 리롤 | 원하는 두 성장 항목의 조합 탐색, 결과 확인 후 환생 적용·저장 |
| 스킬 자동 교체 | 교체 대상과 목표 스킬을 선택해 반복. 실패 복구, 성공 저장, 획득한 목표 보호 |

| 유물 프리셋·최적화 | 용병별 배치 저장·일괄 복원, 다른 용병에게 빌려준 유물 회수, 게임 기본 최적화 실행 |
| 딜·힐 미터기 | 양 팀 용병의 누적 피해와 유효 치유를 전투 중 표시 |
| 전투 분석·비교 | 스킬별 피해·치유·보호막·CC 등 최근 전투 기록 확인 및 두 경기 비교 |
| 전투 배속·성능 편의 | 추가 2·3·4배속, Z/X 배속 변경, 미터기·전투 기록 수집 켜기/끄기 |

성장 계산과 환생은 **미리보기 → 사용자가 적용·저장**하는 방식입니다. 스킬·유물 자동 작업은 시작 후 조건에 맞는 결과를 자동으로 반영·저장하므로, 실행 전에 대상과 목표를 확인해 주세요.

## 처음 사용하는 방법

사용 환경은 **Windows x64 + Steam에 설치된 에스라봉**입니다. 런처에 필요한 .NET이 포함되어 있어 Codex나 개발 도구를 따로 설치할 필요가 없습니다.

1. Steam에서 에스라봉을 설치하고 게임에서 캠페인을 한 번 저장합니다.
2. 게임을 저장하고 종료합니다.
3. [Releases](https://github.com/Eslabot/eslabot/releases/latest)에서 **`EslabotLauncher-win-x64-버전.zip`**을 받습니다.
4. PC의 로컬 폴더에 압축을 풉니다.
5. **에슬라봇 런처.exe**를 실행합니다.
6. 게임 설치 위치를 확인합니다. 자동으로 찾지 못하면 **게임 위치**에서 지정합니다.
7. **최신 버전 동기화**를 누릅니다.
8. **사용 가능**이 표시되면 **에슬라봇 실행**을 누릅니다.

최초 준비 때는 설치된 게임 데이터를 PC 안에서 약 2GB 복사·검증합니다. 게임 데이터가 변경된 새 빌드에서도 새 로컬 사본을 준비할 수 있습니다. 배포 파일에는 게임 원본이나 개인 세이브가 포함되어 있지 않습니다.

기존 개발용 모드를 사용했다면 **처음 동기화하기 전에 [기존 모드 가져오기]에서 기존 runtime 폴더를 선택**해 주세요. 이미 새 모드 저장본이 있으면 덮어쓰지 않도록 가져오기를 제한합니다.

## 게임이나 모드가 업데이트됐을 때

**게임 저장·종료 → Steam에서 게임 업데이트 완료 → 런처 실행 → 최신 버전 동기화 → 사용 가능 확인 → 에슬라봇 실행**

- 개발자가 검사·수정해서 공개한 호환 버전을 받아 적용합니다.
- 런처 업데이트가 포함되면 런처 자체를 갱신하고 다시 엽니다.
- 새 게임 빌드의 검증본이 아직 공개되지 않았다면 **호환성 확인 중**으로 표시합니다.
- 게임 패치 분석과 수정본 공개는 개발자가 진행합니다. 사용자의 동기화 버튼은 공개된 검증본을 받는 기능입니다.
- 게임을 실행 중이라면 저장하고 종료한 뒤 동기화해 주세요.

## 세이브는 어떻게 관리하나요?

모드 저장본과 설정은 기본적으로 **`%LOCALAPPDATA%\Eslabot\data`**에 따로 보관합니다. 런처의 **저장 폴더** 버튼으로 열 수 있습니다.

- 처음에는 기존 게임 저장본을 복사해 별도 모드 환경을 준비합니다.
- **1.0.5부터 모드에서 저장한 캠페인 진행본을 공식 Steam 저장 폴더에도 자동 반영합니다.** 별도로 파일을 옮길 필요가 없습니다.
- 온라인 실행 전에 Steam의 기존 저장 상태를 확인하고, 게임 종료 후 Steam 클라이언트의 업로드 완료 응답과 파일 해시를 대조합니다. **런처에 ‘Steam Cloud 동기화 완료’가 표시될 때까지 기다려 주세요.**
- Steam 로그인과 게임의 Steam Cloud 사용 설정이 필요합니다. 저장 즉시 서버 업로드가 끝나는 방식은 아니며, 오프라인·연결 오류·용량 부족 시에는 로컬 저장본을 보존하고 동기화 대기로 표시합니다.
- Steam과 모드에서 각각 진행해 저장본이 달라졌다면 사용할 진행본을 직접 선택합니다. 기존 파일은 로컬에 백업하며 서로 다른 진행을 자동으로 합치지 않습니다.
- 모드 업데이트 시 프로그램 버전과 저장본을 분리해 유지합니다.
- F5 보호 저장점은 일반 저장이나 자동 리롤의 성공 저장으로 바뀌지 않습니다. 새 복귀 지점을 만들려면 직접 F5를 다시 눌러 주세요.

Steam Cloud 연동 대상은 게임의 캠페인 저장 파일입니다. 모드 전용 설정·분석 기록·F5 보호 저장점 관리 정보는 로컬 데이터 폴더에 보관하며, 배포 서버에는 개인 세이브를 전송하지 않습니다. **1.0.4 이하를 사용 중이라면 먼저 최신 버전 동기화로 런처를 갱신해 주세요.**

자세한 저장·불러오기 동작과 난수 옵션은 [상세 가이드](docs/USAGE.md#저장과-불러오기-f5f10)를 확인해 주세요.

## 피드백과 현재 검증 범위

문제가 있다면 공유 글의 댓글 등 피드백을 남기는 곳에 **게임 버전, 모드 버전, 사용 기능, 재현 순서, 오류 문구**를 함께 적어 주세요. 아이디어와 수정 제안도 환영합니다. 화면이나 기록을 공유할 때 개인 정보가 포함되지 않았는지 확인해 주세요.
