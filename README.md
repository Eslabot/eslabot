# 에스라봇 · Eslabot

**에스라봉의 성장·육성·리롤·전투 분석 기능을 모은 Windows용 비공식 모드 패키지입니다.**

[최신 버전 다운로드](https://github.com/Eslabot/eslabot/releases/latest) · [설치·업데이트 안내](https://github.com/Eslabot/eslabot/) · [기능별 상세 사용법](docs/USAGE.md)

## 안녕하세요

에스라봉을 즐기면서 용병을 키우거나 스킬과 유물을 바꿀 때, 직접 확인하고 반복해야 하는 부분을 조금 편하게 만들고 싶어서 시작한 개인 프로젝트입니다.

처음에는 제가 쓰려고 필요한 기능을 하나씩 붙였는데, 다른 분들도 편하게 써 보실 수 있도록 **에스라봇**이라는 이름으로 공유하게 됐습니다. 게임을 계속 즐기는 동안 필요한 부분을 조금씩 보완해 갈 생각입니다. 다만 개인 취미로 만드는 도구라 모든 패치에 바로 대응하거나 일정한 업데이트 주기를 약속하기는 어렵습니다.

육성 기준과 추천에는 커뮤니티 공략과 게임 내 정보를 참고했습니다. 제가 잘못 이해했거나 계산에 빠뜨린 부분이 있을 수 있으니 추천 결과는 참고용으로 봐 주세요. 잘못된 내용, 불편한 점, 있으면 좋을 기능 모두 편하게 의견 주시면 좋겠습니다.

## 어떤 기능이 들어 있나요?

| 기능 | 주요 내용 |
|---|---|
| 성장 계산·20레벨 성장작 | 능력치 중요도와 통과선을 설정해 성장 결과 탐색. 미리보기 확인 후 직접 적용·저장 |
| 육성·카드 추천 | 보유 용병별 육성 목표 관리, 능력치·스킬·특화·마스터리 선택 비교, 카드 선택창 옆 추천 |
| 환생 훌훌 리롤 | 원하는 두 성장 항목의 조합 탐색, 결과 확인 후 환생 적용·저장 |
| 스킬 자동 교체 | 교체 대상과 목표 스킬을 선택해 반복. 실패 복구, 성공 저장, 획득한 목표 보호 |
| 유물 자동 재설정 | 전체 품질 또는 옵션별 목표를 기준으로 반복 재설정하고 목표 충족 시 저장 |
| 유물 프리셋·최적화 | 용병별 배치 저장·일괄 복원, 다른 용병에게 빌려준 유물 회수, 게임 기본 최적화 실행 |
| 딜·힐 미터기 | 양 팀 용병의 누적 피해와 유효 치유를 전투 중 표시 |
| 전투 분석·비교 | 스킬별 피해·치유·보호막·CC 등 최근 전투 기록 확인 및 두 경기 비교 |
| 전투 배속·성능 편의 | 추가 2·3·4배속, Z/X 배속 변경, 미터기·전투 기록 수집 켜기/끄기 |
| 마켓 정렬 | 용병의 1레벨 능력치 종합 평가를 기준으로 좋은 순·낮은 순 정렬 |
| F5/F10 저장·복구 | F5로 보호 저장점을 만들고 F10으로 복귀. 자동 작업의 성공 저장과 별도로 유지 |
| 공통 조작 | 상단 도구 메뉴, 용병 그림 선택·검색, ESC로 창 닫기, F9로 자동 작업 중단 |

성장 계산과 환생은 **미리보기 → 사용자가 적용·저장**하는 방식입니다. 스킬·유물 자동 작업은 시작 후 조건에 맞는 결과를 자동으로 반영·저장하므로, 실행 전에 대상과 목표를 확인해 주세요.

## 처음 사용하는 방법

사용 환경은 **Windows x64 + Steam에 설치된 에스라봉**입니다. 런처에 필요한 .NET이 포함되어 있어 Codex나 개발 도구를 따로 설치할 필요가 없습니다.

1. Steam에서 에스라봉을 설치하고 게임에서 캠페인을 한 번 저장합니다.
2. 게임을 저장하고 종료합니다.
3. [Releases](https://github.com/Eslabot/eslabot/releases/latest)에서 **`EslabotLauncher-win-x64-버전.zip`**을 받습니다.
4. OneDrive 동기화 폴더 밖의 로컬 폴더에 압축을 풉니다.
5. **`에스라봇 런처.exe`**를 실행합니다.
6. 게임 설치 위치를 확인합니다. 자동으로 찾지 못하면 **게임 위치**에서 지정합니다.
7. **최신 버전 동기화**를 누릅니다.
8. **사용 가능**이 표시되면 **에스라봇 실행**을 누릅니다.

최초 준비 때는 설치된 게임 데이터를 PC 안에서 약 2GB 복사·검증합니다. 게임 데이터가 변경된 새 빌드에서도 새 로컬 사본을 준비할 수 있습니다. 배포 파일에는 게임 원본이나 개인 세이브가 포함되어 있지 않습니다.

기존 개발용 모드를 사용했다면 **처음 동기화하기 전에 [기존 모드 가져오기]에서 기존 runtime 폴더를 선택**해 주세요. 이미 새 모드 저장본이 있으면 덮어쓰지 않도록 가져오기를 제한합니다.

## 게임이나 모드가 업데이트됐을 때

**게임 저장·종료 → 런처 실행 → 최신 버전 동기화 → 사용 가능 확인 → 에스라봇 실행**

- 개발자가 검사·수정해서 공개한 호환 버전을 받아 적용합니다.
- 런처 업데이트가 포함되면 런처 자체를 갱신하고 다시 엽니다.
- 새 게임 빌드의 검증본이 아직 공개되지 않았다면 **호환성 확인 중**으로 표시합니다.
- 게임 패치 분석과 수정본 공개는 개발자가 진행합니다. 사용자의 동기화 버튼은 공개된 검증본을 받는 기능입니다.
- 게임을 실행 중이라면 저장하고 종료한 뒤 동기화해 주세요.

## 세이브는 어떻게 관리하나요?

모드 저장본과 설정은 기본적으로 **`%LOCALAPPDATA%\Eslabot\data`**에 따로 보관합니다. 런처의 **저장 폴더** 버튼으로 열 수 있습니다.

- 처음에는 기존 게임 저장본을 복사해 별도 모드 환경을 준비합니다.
- 이후 모드에서 진행한 내용은 별도 모드 저장본에 저장됩니다.
- **모드 진행 내용을 Steam 원본 세이브로 자동 반영하지 않습니다.**
- 모드 업데이트 시 프로그램 버전과 저장본을 분리해 유지합니다.
- F5 보호 저장점은 일반 저장이나 자동 리롤의 성공 저장으로 바뀌지 않습니다. 새 복귀 지점을 만들려면 직접 F5를 다시 눌러 주세요.

자세한 저장·복구 동작과 난수 옵션은 [상세 가이드](docs/USAGE.md#저장과-복구-f5f10)를 확인해 주세요.

## 자주 쓰는 단축키

| 키 | 기능 |
|---|---|
| F5 | 현재 캠페인의 보호 저장점 설정 |
| F10 | 마지막으로 직접 만든 F5 저장점으로 복귀 |
| F6 | 스킬 자동 교체 창 |
| F7 | 육성·카드 추천 상세 설정 |
| F8 | 성장 계산 창 |
| F9 | 진행 중인 자동 작업 중단 |
| ESC | 열린 선택창·도구창 닫기 |
| Z / X | 전투 배속 한 단계 낮춤 / 높임 |
| Ctrl+F3 / Ctrl+F4 | 딜 미터기 / 전투 기록 수집 켜기·끄기 |

구단 관리 화면과 전투 등 각 기능을 사용할 수 있는 화면에서 동작합니다.

## 피드백과 현재 검증 범위

문제가 있다면 공유 글의 댓글 등 피드백을 남기는 곳에 **게임 버전, 모드 버전, 사용 기능, 재현 순서, 오류 문구**를 함께 적어 주세요. 아이디어와 수정 제안도 환영합니다. 화면이나 기록을 공유할 때 개인 정보가 포함되지 않았는지 확인해 주세요.

공식 0.82.4 / Steam 빌드 26059814를 기준으로 새 폴더·별도 앱 프로필에서 실행과 실제 게임 엔진의 F5/F10·보호 저장점 검사를 진행합니다. 다른 실물 PC나 독립 Windows VM에서의 검증은 아직 완료하지 않았습니다. 향후 모든 게임 패치에 대한 호환성을 보장하지는 않습니다.

이 프로젝트는 게임 제작사와 별개인 개인 비공식 도구입니다. 추천은 모든 용병과 상황에 대한 절대적인 최적해가 아닙니다. 중요한 플레이 전에는 별도로 세이브를 백업해 주세요.

**기능별 사용 순서와 설명은 [상세 사용 가이드](docs/USAGE.md)에 정리했습니다.**
