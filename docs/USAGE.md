# 에스라봇 상세 사용 가이드

[소개로 돌아가기](../README.md) · [다운로드](https://github.com/Eslabot/eslabot/releases/latest) · [설치·업데이트 안내](https://github.com/Eslabot/eslabot/)

게임 내 상단 **도구 ▾** 메뉴에서 기능을 열 수 있습니다. 일부 기능은 구단 관리 화면이나 용병 상세 화면에서 사용할 수 있습니다. 이 문서는 공개된 런처 패키지의 사용 방법을 설명합니다.

## 런처 사용

| 버튼·항목 | 설명 |
|---|---|
| 에스라봇 실행 | 설치된 게임과 승인된 모드의 호환성을 확인하고 전용 모드 환경 실행 |
| 최신 버전 동기화 | 공개된 최신 호환 정보를 확인하고 필요한 모드·런처 업데이트 적용 |
| 게임 위치 | eslabong.exe와 eslabong.pck가 있는 Steam 게임 설치 폴더 지정 |
| 기존 모드 가져오기 | 기존 개발용 runtime의 저장본과 설정 복사. 첫 동기화 전에 사용 |
| 저장 폴더 | 별도로 관리되는 모드 저장본·설정 폴더 열기 |
| 업데이트 내역 | 공개 안내 페이지 열기 |
| 오프라인 실행 | 검증된 로컬 설치본으로 Steam 연결 없는 로컬 캠페인 실행 |

오프라인 실행에서도 설치된 게임과 모드의 버전 일치가 필요합니다. 온라인 동기화에는 인터넷이 필요하고, 오프라인 실행에서는 온라인·Steam 연동 기능을 사용할 수 없습니다.

게임 실행 중에는 저장·종료한 뒤 업데이트해 주세요. 새 게임 버전이 검증되지 않았다면 기존 모드를 임의로 실행시키지 않고 호환성 확인 안내를 표시합니다.

## 저장과 복구 F5/F10

구단 관리 화면에서 사용합니다.

1. 보존할 상태에서 **F5**를 누릅니다.
2. 저장 완료 안내를 확인합니다. 현재 캠페인의 되돌리기 지점이 만들어집니다.
3. 이후 플레이하다 **F10**을 누르면 해당 캠페인의 마지막 F5 저장점으로 복귀합니다.
4. 새 상태를 복귀 지점으로 바꾸고 싶다면 직접 **F5**를 다시 누릅니다.

일반 메뉴 저장, 자동 저장, 성장 적용 저장, 스킬·유물 자동 작업의 성공 저장은 F5 저장점을 바꾸지 않습니다. 캠페인별 저장점은 재실행 후에도 유지됩니다. F5 저장점이 없으면 안내만 표시하고 다른 저장본을 임의로 불러오지 않습니다.

자동 작업 중에는 **F9**로 중단한 뒤 저장·복구를 사용해 주세요. F10은 해당 저장점 이후의 진행을 되돌리는 기능이므로 복귀 시점을 확인해 주세요.

### 불러오기 난수 옵션

F10은 게임 Gameplay 설정의 **Allow new rolls when loading**을 따릅니다.

- 켜짐: 불러올 때 새 난수로 진행합니다.
- 꺼짐: 저장된 난수 상태를 유지합니다.

같은 상태를 불러온다고 항상 다른 옵션이나 스킬이 나오는 것은 아닙니다. 자동 작업은 실패 복구와 성공 결과 재현을 별도로 처리하며, 이 공식 설정 파일을 임의로 바꾸지 않습니다.

## 성장 계산·20레벨 성장작

**도구 → 성장 계산**, 또는 **F8**로 엽니다.

1. 20레벨 미만 용병을 선택합니다.
2. 능력치별 중요도와 통과선을 설정합니다.
3. **계산 시작**으로 성장 결과를 탐색합니다.
4. 결과창에서 레벨별 증가량, 최종 능력치, 최대치 대비 비율, 훈련비를 확인합니다.
5. 원하는 결과라면 **적용·저장**을 직접 누릅니다.
6. 원하지 않으면 **미리보기 버리기** 후 조건을 바꿉니다.

미리보기 탐색은 실제 용병·재화·게임 저장본에 결과를 적용하지 않습니다. **적용·저장**할 때 게임의 훈련을 실행하고 결과를 작업 슬롯에 저장합니다. 적용에 필요한 게임 조건과 비용은 충족해야 합니다. 탐색은 F9로 중단할 수 있습니다.

## 육성 목표·카드 추천

**도구 → 카드 추천**, 또는 **F7**로 엽니다.

보유 용병을 고유 ID로 추적하며, 능력치·스킬·특화·마스터리 선택을 비교합니다. 카드 선택창 옆에도 추천이 표시되고, 실제 카드 선택은 사용자가 직접 합니다.

1. 용병 그림을 눌러 대상을 고릅니다.
2. 현재 적용된 직군별 육성안과 목표 수치를 확인합니다.
3. 다른 방향을 원하면 직군안을 바꾸거나 직접 중요도·목표를 설정합니다.
4. 필요하면 미래 선택 경로까지 비교하는 옵션을 조정합니다.
5. 자동 기준으로 되돌리고 싶으면 **자동 추천 복원**을 사용합니다.

공략 근거가 부족한 용병은 직군 기본안·추정으로 안내합니다. 미래 자연 성장을 평균으로 가정하는 부분과 제한된 탐색 범위가 있어 모든 상황의 최적해를 보장하지 않습니다. F8에서 실제 성장 결과를 확보하거나 새 카드가 나오면 다시 판단할 수 있습니다.

## 환생 훌훌 리롤

**도구 → 환생 훌훌 리롤**로 엽니다. 시간의 방 용병 카드의 **훌훌 선택**으로도 접근할 수 있습니다.

1. 대상 용병과 훌륭함을 붙일 두 성장 항목을 선택합니다.
2. **목표 훌훌 찾기**로 조합을 탐색합니다.
3. 발견한 조합과 1레벨 결과를 확인합니다.
4. **환생 적용·저장**을 눌러 실제 환생을 실행합니다.
5. 환생 후에는 필요에 따라 F8 성장 계산을 이어서 사용합니다.

탐색 중에는 실제 용병·명성·저장본을 변경하지 않습니다. 적용 시에는 게임의 환생 조건과 비용을 따릅니다. 환생 전 복구본과 환생 후 결과는 별도 작업 슬롯으로 관리하고 F5 보호 저장점은 유지합니다. 미리보기 이후 용병이나 구단 상태가 바뀌면 다시 탐색해야 할 수 있습니다.

## 스킬 자동 교체

**도구 → 스킬 교체**, 또는 **F6**로 엽니다.

1. 용병을 고릅니다.
2. **교체할 현재 스킬**과 **원하는 목표 스킬**을 같은 개수로 선택합니다.
3. 목표와 대상을 확인하고 **자동 교체 시작**을 누릅니다.
4. 중단하려면 **F9**를 누릅니다.

실패 시 최근 성공 상태로 복구하고 다음 시도를 진행합니다. 목표를 얻으면 저장하며, 이미 획득한 목표 스킬을 이후 교체 대상으로 다시 돌리지 않도록 보호합니다. 선택하지 않은 스킬은 교체 계획에서 제외합니다.

이 기능은 미리보기 전용이 아니라 실제 성공 결과를 반영·저장하는 자동 작업입니다. 교체할 대상을 먼저 확인하고, 필요하면 시작 전 F5 저장점을 만들어 주세요. F5 저장점은 자동 성공 저장과 별도로 유지됩니다.

## 유물 자동 재설정

**도구 → 유물 자동 재설정**으로 엽니다.

1. 재설정할 유물을 선택합니다.
2. 전체 품질 또는 옵션별 목표를 지정합니다.
3. 자동 재설정을 시작합니다.
4. 목표 충족 결과를 확인합니다. 중단은 **F9**입니다.

시작 상태와 성공 결과를 저장하고, 기준에 맞는 결과를 유지하도록 반복합니다. 장착 유물 처리와 작업 결과 저장은 도구의 절차에 따라 진행하며, F5 보호 저장점은 유지됩니다. 목표를 만족하는 결과가 언제 나올지는 보장하지 않습니다.

## 유물 프리셋·게임 기본 최적화

용병 상세 화면의 **유물 프리셋**에서 현재 장착 배치를 등록할 수 있습니다.

- 여러 용병의 배치를 저장한 뒤 **전체 용병 적용**으로 일괄 복원합니다.
- 다른 용병이 빌려 쓰는 유물도 동일한 유물 개체를 찾아 회수합니다.
- 중복 등록, 소실·판매 중인 유물, 직업 제한, 열리지 않은 슬롯 등을 적용 전에 확인합니다.
- 유물 잠금·즐겨찾기를 유지하고 게임의 장착·저장 처리를 따릅니다.

**유물최적화**는 현재 선택한 출전 명단에 대해 게임 기본 최적화를 실행하는 기능입니다. 모드가 모든 조합을 독자적으로 계산해 절대 최적 배치를 확정하는 기능으로 해석하지 말아 주세요.

## 딜·힐 미터기와 전투 분석

### 전투 중 표시

양 팀 용병의 누적 피해를 표시하고, 치유가 있는 용병은 유효 치유도 함께 표시합니다. 용병 그림과 스쿼드 순서로 대상을 구분합니다.

- **Ctrl+F3**: 딜 미터기 켜기·끄기
- **Ctrl+F4**: 전투 기록 수집 켜기·끄기

화면 표시와 기록 수집은 각각 설정할 수 있습니다.

### 최근 전투 분석

용병 상세의 **최근 전투 분석**에서 수집된 캠페인 전투를 확인합니다. 캠페인별 최근 60경기를 보관하고 용병 ID로 구분합니다.

- 스킬별 사용·피해·유효 치유·보호막·CC·부활 등 기록 확인
- 수집 가능한 전투에서 초과 치유·식별된 흡혈·생존 시간·동시 광역 피해 확인
- 두 경기 선택 후 피해·치유·보호막 등의 차이와 당시 장비 비교

이 기록은 실제 전투 관측을 바탕으로 합니다. 상대, 레벨, 스킬, 전투 흐름이 달라지면 결과도 달라집니다. 두 경기의 차이를 특정 유물 하나의 확정 기여량으로 해석할 수는 없으며, 일부 지속 효과나 지연 적중은 미분류될 수 있습니다.

## 전투 배속·성능 편의

추가 **2·3·4배속**을 지원하며, 전투 중 **Z**로 한 단계 낮추고 **X**로 한 단계 높일 수 있습니다.

미터기와 기록 수집을 필요에 따라 꺼서 수집·갱신 부담을 줄일 수 있습니다. 배속은 전투 진행 속도를 조절하는 기능이며 실제 처리 속도는 PC 성능과 전투 상황에 영향을 받습니다. 게임 버전에 맞춰 일부 전투 효과의 렌더링 오류 방지도 적용합니다.

## 마켓 용병 정렬

마켓 용병 목록의 정렬 메뉴에서 **1레벨 능력치 종합 · 좋은 순 / 낮은 순**을 선택합니다.

최초 체력·전투력·방어·속도의 직업별 1레벨 평가를 같은 비중으로 비교합니다. 성장 스타일이나 잠재력, 현재 레벨의 장비·성장분 전체를 합친 최종 성능 순위는 아닙니다. 초기 기록이 없는 용병은 기록이 있는 용병 뒤에 표시합니다. 이 정렬에서는 샤이니가 먼저 표시됩니다.

## 공통 조작

용병 선택 영역을 누르면 그림 카드 목록이 열리며 이름·직업 검색과 페이지 이동으로 대상을 고를 수 있습니다. **ESC**는 열린 선택창과 도구창을 닫는 데 사용합니다. 자동 작업 정지는 **F9**입니다. 저장·적용 중에는 처리가 끝날 때까지 기다려 주세요.

## 저장본 위치와 기존 모드 가져오기

기본 모드 데이터 폴더는 **`%LOCALAPPDATA%\Eslabot\data`**입니다. 런처의 **저장 폴더**로 열 수 있습니다.

- 최초 설치 시 Steam 게임의 기존 캠페인 저장본을 별도로 복사합니다.
- 모드에서 진행한 저장본은 이 별도 환경에 보관합니다.
- Steam 원본 세이브로 모드 진행을 자동으로 되쓰기하지 않습니다.
- 프로그램 버전과 데이터 디렉터리는 분리되어 있습니다. 중요한 진행 전에는 게임을 종료한 상태에서 데이터 폴더를 별도로 백업해 주세요.

기존 개발용 모드 사용자는 **첫 동기화 전에 [기존 모드 가져오기]에서 기존 runtime 폴더**를 선택합니다. F5 보호 저장점과 관련 설정까지 가져오기 위한 경로입니다. 이미 새 모드 데이터가 있으면 덮어쓰지 않도록 가져오기를 제한하므로 먼저 순서를 확인해 주세요.

## 업데이트·문제 해결

| 상황 | 확인할 내용 |
|---|---|
| 게임 위치를 찾지 못함 | Steam 설치 완료 후 게임 위치에서 eslabong.exe와 eslabong.pck가 있는 폴더 지정 |
| 가져올 캠페인 저장본이 없음 | 원본 게임에서 캠페인을 한 번 저장한 뒤 게임을 종료하고 재시도 |
| 호환성 확인 중 | 해당 공식 게임 빌드의 수정본 공개를 기다린 뒤 다시 동기화 |
| 게임을 종료하라는 안내 | 게임에서 직접 저장하고 종료한 뒤 재시도 |
| 이미 최신 호환 버전 | 정상 상태이며 실행 가능 표시를 확인한 뒤 플레이 |
| 다운로드·검증 실패 | 표시된 오류를 확인하고 다시 동기화. 기존 저장본을 삭제하지 말고 오류 문구 기록 |
| F10이 다른 결과를 만들지 않음 | 공식 불러오기 난수 옵션과 어떤 저장점으로 복귀했는지 확인 |
| 새 PC에서 재현되는 오류 | 게임·모드·Windows 버전, 오류 문구, 실행 순서를 함께 전달 |
